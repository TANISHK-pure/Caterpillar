# Caterpillar

Collection of MATLAB, ROS 2, simulation, and 3D model assets for the Caterpillar/NFP work.

## Contents

- `3D Models/` - truck and machine models
- `MILP/` and `NFP/` - MATLAB optimization code
- `Simulations/` - presentation and video assets
- `ros2_ws/` - ROS 2 workspace sources and package code
- `ttsk12_matlab/` - additional MATLAB planners

## Notes

- Generated ROS 2 build outputs, install trees, logs, Python bytecode, and archive exports are excluded from version control.
- For the ROS 2 workspace, build from `ros2_ws/src` with your normal `colcon` workflow.
